# Turnstile

The port and everything that is the same for every adapter.

- `Turnstile`: the port. `authorize`, its raising form, `check`, `batch`, `filter`, `scope`, `explain`, and `review` delegate to `Turnstile.Port`, which resolves the configuration, asks the adapter, denies an unknown subject kind before asking and an unreachable engine after, stamps a `Turnstile.Decision`, and publishes the call as one `[:turnstile, :decision]` telemetry event.
- `Turnstile.Adapter`: the behaviour an adapter implements: `authorize`, `check`, `batch`, `scope`, and the optional `explain` and `around_query`, plus `scope_cap/0`, the optional `settle/0`, and an options schema.
- The values that cross the port: a subject as a `{kind, id}` tuple, an object as a `{type, id}` tuple, an environment as a map of the caller's facts with `now` beside them, `Turnstile.Answer`, `Turnstile.Decision`, `Turnstile.PolicyVersion`, `Turnstile.Exemption`, and the one exception `%Turnstile.Error{reason, detail}`. An adapter answers one `%Turnstile.Answer{verdict, reason, version, meta}`: a rule that narrows comes back as `{dynamic, answer}`, and an explanation is the answer with what matched on `meta`.
- The values that cross the port share `Turnstile.Edge`: `to_map/1` and `from_map/1` on each struct, over one field specification per struct.
- `Turnstile.Test.Fake`: the in-memory adapter tests bind. Its rules are a table in an `Agent`, one per test, and a table told to fail answers every call with an engine error.
- `use Turnstile.Schema`: the fact mapping, column by column, from an application's schemas to the three fact kinds.
- `use Turnstile.Repo`: the seam. `lib/turnstile/core/surface.ex` lists every `Ecto.Repo` function in one of four buckets; the overrides hand each query, write, and raw call to `lib/turnstile/adapter/seam.ex` with the `turnstile:` option, a decision or an exemption, resolved into the mediation of `lib/turnstile/core/mediation.ex`. A call on a protected schema that carries neither raises `%Turnstile.Error{reason: :unmediated}` before any SQL; a single-row write to an audited schema publishes its change event inside the write's transaction.
- `Turnstile.Conformance.RepoCase`: the test that diffs the surface against a repo's exports and calls every non-plumbing function on a protected schema without a decision.
- `Turnstile.Config`: the one configuration struct, validated once at boot; `Turnstile.Test.with_config/1,2` overrides it per process in tests.
- `Turnstile.Conformance`: the scenario table, the `scenario` macro, and `Turnstile.Conformance.AdapterCase`, the Tier 1 template every adapter, in this repository or outside it, proves itself against: the port's invariants as properties over `Turnstile.Conformance.Gen`, the two shape tests, the fail-closed case, and the revocation-latency template. An adapter that keeps state of its own seeds it through `Turnstile.Conformance.Seed`. This package's test support holds the neutral fixture, `Turnstile.Fixture`, and its `World`.
- `Turnstile.Test.Cluster`: the ephemeral Postgres cluster `mix test` starts. `Turnstile.Test.Clock.set/1` fixes the time the calling process's port calls read, and `Turnstile.Test.queries/2` lists the SQL a function ran for the shape tests.

`glossary.md` defines the words this package owns. This package's `lib` depends on `ecto` and `nimble_options`; `ecto_sql` and `postgrex` serve its own tests only, and Boundary checks that no call from `lib` reaches them.
